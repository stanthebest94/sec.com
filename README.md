# Chukwu Stanley Emeka - Professional Portfolio

A static professional portfolio website designed for GitHub Pages.

## Positioning
Business Operations & Automation Specialist | Sales | Virtual Assistant | Microsoft Power Platform

## Stack
- HTML
- CSS
- JavaScript
- GitHub Pages

## Deployment
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders in this project.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Before publishing
- Replace the placeholder LinkedIn URL in `index.html`.
- Replace the placeholder GitHub URL in `index.html`.
- Replace the CV file in `assets/` with your preferred public CV copy.
